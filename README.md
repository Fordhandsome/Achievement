## 🐳 Running This Portfolio Website

### Option 1: View Online
Open the live site: **[https://fordhandsome.github.io/Achievement/](https://fordhandsome.github.io/Achievement/)**

### Option 2: Run with Docker
```bash
git clone https://github.com/Fordhandsome/Achievement.git
cd Achievement
docker compose up -d --build
```
Then open **[http://localhost:3000](http://localhost:3000)** in your browser.

### Option 3: Run with Node.js (Vite)
```bash
cd website
npm install
npm run dev
```

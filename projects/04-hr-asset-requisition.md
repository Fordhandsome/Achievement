# Case Study: Smart HR & PC Asset Stock Management System (Web & Barcode Portal)

> **Category:** Enterprise Full-Stack Web Application & Warehouse/Asset Workflow  
> **Role:** AI & Technology / Full-Stack Solutions Developer  
> **Tools & Tech:** React, Vite, TypeScript, Node.js, Express, MySQL, Barcode/QR Web API, HTML5 Canvas Signature, Responsive Mobile UI  
> **Status:** Production / Implemented  

---

## 📌 Executive Summary
ระบบเว็บแอปพลิเคชันบริหารจัดการสต็อกและเบิกจ่ายอุปกรณ์สำนักงานและไอที (**Smart HR & PC Asset Stock Management**) แบบครบวงจร (End-to-End) พัฒนาขึ้นเพื่อทดแทนกระบวนการเบิกจ่ายด้วยกระดาษเดิม โดยผสานฟังก์ชัน **การสแกนบาร์โค้ดผ่านกล้องมือถือ**, **การตรวจนับและปรับปรุงยอดสต็อก (Stock Check & Adjust)**, **การสร้างและพิมพ์แผ่น Barcode Sheet ขนาด A4**, และ **ระบบเบิกอุปกรณ์ 4 ขั้นตอนพร้อมลงนามด้วยลายเซ็นดิจิทัล (Digital Signature)** ช่วยลดขั้นตอนการเบิกจ่ายจาก 1-2 วัน เหลือเพียง 3-5 นาที และขจัดปัญหาของในคลังไม่ตรงกับระบบได้ 100%

---

## 🎯 1. Situation & Problem (ปัญหาเดิมและสถานการณ์)
* **การใช้ใบเบิกกระดาษแบบดั้งเดิม (Paper Requisition):** พนักงานต้องเดินนำแบบฟอร์มไปให้หัวหน้างานเซ็น แล้วนำมาส่งที่ฝ่าย HR ทำให้เอกสารตกค้างและสูญหายบ่อยครั้ง
* **ยอดสต็อกในบัญชีไม่ตรงกับของจริง (Inventory Discrepancy):** เมื่อไม่มีระบบตัดสต็อก ณ จุดรับของ ทำให้ยอดคงเหลือคลาดเคลื่อน ไม่ทราบว่าอุปกรณ์ชิ้นใดใกล้หมด
* **ไม่มีระบบพิมพ์บาร์โค้ดสำหรับจัดระเบียบคลัง:** อุปกรณ์ใหม่และอะไหล่ไม่มีป้ายบาร์โค้ดมาตรฐาน ทำให้การตรวจนับสต็อกประจำเดือนต้องใช้เวลานานและนับซ้ำซ้อน
* **ขาดหลักฐานการส่งมอบที่ตรวจสอบได้:** เมื่อเกิดกรณีอุปกรณ์สูญหาย ไม่สามารถตรวจสอบย้อนหลังได้ว่าผู้ใดเป็นผู้รับมอบไปเมื่อใด

## 🛠️ 2. Task & Solution Architecture (เป้าหมายและการออกแบบระบบ)
พัฒนา Full-stack Web Portal ที่รองรับทั้งพนักงานทั่วไป (Self-Service) และเจ้าหน้าที่ผู้ดูแลคลัง (HR Admin):

```
[ พนักงานทั่วไป ]                                 [ เจ้าหน้าที่ HR / Admin ]
       ↓                                                    ↓
[ 1. กรอกข้อมูลพนักงาน ]                        [ 1. รับของเข้า Inbound ตาม PO ]
       ↓                                                    ↓
[ 2. เลือกอุปกรณ์ & จำนวน ]                     [ 2. จัดการ Master & พิมพ์ Barcode A4 ]
       ↓                                                    ↓
[ 3. เซ็นชื่อดิจิทัลผ่านหน้าจอ ]                 [ 3. ตรวจนับสต็อกจริง & ปรับยอด (Adjust) ]
       ↓                                                    ↓
[ 4. ส่งคำขอเข้าคิวเรียลไทม์ ] ─── (Real-time Queue) ──→ [ 4. ตรวจสอบ สแกนจ่ายของ & พิมพ์ Slip ]
```

### ฟังก์ชันหลักในระบบ (Core Modules):
1. **Inbound & Receiving:** บันทึกรับพัสดุและอุปกรณ์เข้าคลัง อ้างอิงตามเลขที่ PO พร้อมสแกนตรวจรับ
2. **Item Master Catalog & Barcode Sheet:** ระบบแคตตาล็อกสินค้า และเครื่องมือสร้างไฟล์พิมพ์แผ่นบาร์โค้ด A4 เพื่อนำไปติดกล่องหรือชั้นวางสินค้า
3. **Physical Stock Check & Adjust:** หน้าจอตรวจนับสต็อกจริงเปรียบเทียบกับยอดในระบบ พร้อมบันทึกหมายเหตุการปรับปรุง (Reason Logs) สำหรับการตรวจสอบ (Audit Trail)
4. **4-Step User Requisition Portal (ไม่ต้อง Login):**
   - *Step 1:* กรอกรหัสพนักงาน ชื่อ แผนก (มีระบบจำข้อมูลอัตโนมัติ)
   - *Step 2:* ค้นหาและเลือกรายการอุปกรณ์ที่ต้องการ
   - *Step 3:* ลงนามลายเซ็นดิจิทัลผ่านหน้าจอสัมผัส (HTML5 Canvas Signature)
   - *Step 4:* ยืนยันสำเร็จและสร้างคิวเบิกจ่าย
5. **Admin Dispatch Queue & Slip Printing:** เจ้าหน้าที่ HR ตรวจสอบคำขอ สแกนจ่ายของ และพิมพ์เอกสารใบเบิก A4 เก็บเป็นหลักฐาน

## 🚀 3. Action & Implementation (ขั้นตอนการลงมือปฏิบัติ)
* **Frontend Development (React + Vite + TypeScript):** ออกแบบ UI สไตล์ Aurora Glassmorphism ที่สะอาดตา โหลดรวดเร็ว รองรับทั้งหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์
* **Hardware-Free Camera Scanner:** พัฒนาระบบสแกนบาร์โค้ดโดยใช้กล้องสมาร์ตโฟนผ่าน Web API ช่วยให้พนักงานและ HR ไม่จำเป็นต้องซื้อเครื่องยิงบาร์โค้ดราคาแพง
* **Digital Signature Canvas:** พัฒนาโมดูลเซ็นชื่อสดบนหน้าจอ และบันทึกลายเซ็นเป็นไฟล์ภาพดิจิทัลเชื่อมโยงกับ Transaction การเบิกจ่ายอย่างปลอดภัย
* **Backend & Database (Node.js + Express + MySQL):** ออกแบบฐานข้อมูลแบบ Relational Database ที่มีระบบ Foreign Key, Transaction Lock เพื่อป้องกันยอดสต็อกติดลบ และมีบันทึกประวัติ (Audit Logs) ทุกความเคลื่อนไหว

## 📈 4. Result & Business Impact (ผลลัพธ์เชิงธุรกิจที่วัดผลได้)
* ⚡ **ลดเวลาการดำเนินเรื่องเบิกจ่ายจาก 1-2 วัน เหลือเพียง 3-5 นาที**
* 🍃 **ยกเลิกการใช้กระดาษแบบฟอร์ม 100% (100% Paperless Transition)**
* 📦 **ลดข้อผิดพลาดในยอดสต็อกคงคลังลง 90%+** ด้วยการตัดสต็อกทันทีหลังสแกนจ่ายของ
* 🗂️ **ค้นหาประวัติการเบิกจ่ายย้อนหลังได้ใน 1 วินาที** จากเดิมที่ต้องค้นแฟ้มกระดาษในห้องเก็บเอกสาร
